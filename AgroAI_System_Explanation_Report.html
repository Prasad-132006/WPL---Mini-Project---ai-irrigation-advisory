AgroAI System Explanation

AgroAI is a sugarcane-only irrigation advisory system using React, Express, local MongoDB, and the included 3,000-row historical sugarcane dataset.

The application does not claim a trained AI model, physical sensor connection, or live weather feed. Current moisture is farmer-entered; weather and yield values are historical references.

Architecture

React -> Express authenticated API -> MongoDB

Persistent collections

  • farmers: account identity and bcrypt password hash
  • farms: owned sugarcane plots and current inputs
  • advisories: input snapshots, recommendations, CSV reference, and acceptance

The backend filters by mapped stage and soil, selects the closest historical moisture row, calculates area-adjusted water and pump duration, stores the result, and returns it to React.

Security

Passwords are hashed, sessions use signed HTTP-only cookies, duplicate emails are rejected, API inputs are validated, and all farm and advisory operations are scoped to the authenticated farmer.
