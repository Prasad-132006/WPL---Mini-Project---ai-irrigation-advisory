1. Executive Summary & Objective

The AgroAI Smart Irrigation System is an intelligent agronomic web platform engineered to assist farmers in optimizing water allocation, eliminating over-irrigation before rain events, and preventing crop disease. It pairs interactive React 19 frontend interfaces with empirical agricultural data analysis.

3. How the AI Analysis Engine Works

The intelligence core combines empirical agricultural trial datasets with real-time sensor and meteorological inputs.

The Knowledge Base (FINAL_SUGARCANE_DATASET.csv)

The system ingests thousands of agricultural records containing:

  • Growth_Stage: Germination, Vegetative, Grand growth, Maturity
  • Soil_Type: Loamy, Clay, Sandy, Black soil
  • Humidity_% & Rainfall_Total_mm: Ambient atmospheric metrics
  • Water_Quantity_liters_per_acre: Exact calibrated baseline water volumes
  • Irrigation_Method_Type: Drip, Furrow, Sprinkler recommendations
  • Disease_Severity & Disease_Type: Pathogen vulnerability indicators

Step B: Multi-Factor Feature Matching (findClosestFarmRecord)

When the farmer triggers analysis, the algorithm filters the dataset using hierarchical category matching:

export const findClosestFarmRecord = (dataset, soilType, cropStage) => {
  const stageMatches = dataset.filter((record) =>
    record.Growth_Stage.toLowerCase().includes(cropStage.toLowerCase())
  );
  const records = stageMatches.length ? stageMatches : dataset;
  const soilMatches = records.filter(
    (record) => record.Soil_Type.toLowerCase() === soilType.toLowerCase()
  );
  return (soilMatches.length ? soilMatches : records)[0];
};

4. Mathematical Modeling & Advisory Formulas

1. Rain Probability Correlation Formula

Computes precipitation risk combining live ambient humidity and Doppler radar projections:

Rain Chance (%) = Math.min(95, Humidity_% + (Rainfall_Total_mm / 20))

Rule: If Rain Chance ≥ 70%, irrigation is scheduled for "Tomorrow morning" (after evaluating natural rainfall).

2. Total Water Volume Requirement

Scales the matched field baseline across the specified acreage:

Water Required (Litres) = Farm Area (Acres) × Water_Quantity_liters_per_acre

3. Pump Duration Formulation

Calculates the exact electrical pump run-time based on a standard 2,100 L/hr agricultural pump rating:

Pump Duration (Hours) = Total Water Required (Litres) / 2,100 L/hr
